A voxel game similar to Minecraft. Features procedurally generated terrain with multiple biomes using 2D and 3D perlin noise, newtonian physics-based player movement with digging and placing blocks, simple inventory system with minecraft UI and smooth vertex lighting for indoor and outdoor environments.

To run the project, open the run folder and run the SimpleMiner_Release_x64.exe
To compile, place the SimpleMiner project folder and the Engine folder in the same location. Go to SimpleMiner->Code and open the .sln file.
